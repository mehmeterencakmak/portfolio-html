1. Project Overview

This project is a full-stack personal portfolio website developed as the final assignment for the Internet & Web Programming course. The portfolio serves as a professional showcase of my skills, projects, and background as a Software Engineering student. It integrates all technologies covered during the semester: HTML5, CSS3, JavaScript, PHP, and MySQL.

The application consists of a public-facing portfolio page and a protected admin dashboard. Visitors can view my projects (loaded dynamically from a database via AJAX) and send me messages through a validated contact form. The admin panel allows me to add, edit, and delete portfolio projects after authenticating with a secure session-based login.

4. Database Schema

-- Database: portfolio_db

TABLE admin_users  -- Admin login credentials
  id, username, password_hash (bcrypt), created_at

TABLE projects  -- Portfolio projects (managed via admin)
  id, title, description, tags, image_url, demo_url, github_url, created_at

TABLE messages  -- Contact form submissions
  id, name, email, subject, message, ip_address, created_at

To import: open phpMyAdmin, create a database named portfolio_db, then import portfolio_db.sql. Alternatively run: mysql -u root -p < portfolio_db.sql. After import, visit /admin/setup.php once to seed the admin user (default credentials: admin / Admin123!).

6. Security Measures

SQL Injection: All database queries use PDO prepared statements with bound parameters. XSS: All user-supplied strings are passed through htmlspecialchars() before output and through the custom esc() function in JavaScript. Session Fixation: session_regenerate_id(true) is called immediately after a successful login. Password Storage: Admin password is hashed with PHP's password_hash() (bcrypt, cost factor 10) and verified with password_verify(). Credentials: config.php is excluded from the public Git repository via .gitignore.
